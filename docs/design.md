# 知序 LifeOS 界面设计

## 产品与设计方向

知序是一张有秩序的个人学习与生活工作台。面向同时管理学习、习惯、知识与日常事务的个人，以多位专业 AI 助手协作为特色。视觉采用轻盈、安静的桌面工作环境，让任务与进展有明确位置。

## 设计标记

- 松绿 `#12695B`：主操作、选中导航与完成状态。
- 纸白 `#FFFFFF`：内容工作区。
- 雾灰 `#F5F7F8`：页面背景与次级区域。
- 石墨 `#25332F`：正文和标题。
- 薄荷 `#E7F3EC`：学习启发和欢迎区域。
- 鸢尾 `#EDE9F7`：Agent 协作与知识功能的辅助色。

字体使用系统中的 PingFang SC、Microsoft YaHei、Noto Sans CJK SC 及 Arial；中文正文字号 14px、正文行高 1.65，标题 24–32px，数字适度放大并使用等宽数字。使用系统字体保证服务器部署与低速网络下的稳定显示。

## 布局

公开首页/使用产品导航、价值介绍、多Agent分工、媒体场景、当前会员价格与APK下载；独立/login展示登录注册表单。两者均不加载个人侧栏、搜索、通知或底部功能菜单。登录后/user默认展示完整功能目录，/user?view=overview提供个人概览；后台/admin使用独立管理框架。

登录后的个人功能采用左对齐应用框架，由固定导航、顶部操作栏及具有明确主次的工作区组成。个人概览欢迎区宽而低，以手绘轨道表达多 Agent 围绕共同目标工作；下面用任务清单、助手列表和学习节奏形成不同的信息密度。右栏承载今日安排与成长入口，避免所有内容使用相同尺寸卡片。

```
导航    顶部：当前位置                   搜索 / 账户
        标题与日期
        欢迎与 Agent 轨道图             今日小日历
        真实数据摘要                    今日待办
        专属 AI 助手                    会员入口
        学习与生活清单
```

公开首页移动端使用产品菜单；个人功能登录后收拢为单列并保留5项底部导航。管理后台使用分组导航，手机端提供管理快捷底栏与全部管理菜单抽屉，表格局部滚动保持可读。弹窗在小屏上保留内滚动，所有表单标签持续可见。

## 设计审查

初稿的通用大数字统计与重复卡片可能弱化“学习生活”的主题，因此将视觉重心改为共同目标的 Agent 轨道，数据摘要采用轻量分隔排版，并让待办与助手各自采用更适合的列表形态。取消无意义渐变、装饰性全大写标签和随机动画。

公开首页展示产品内容、真实当前方案与APK；个人统计仅在登录后展示，并全部来自本人API。按钮指向实际动作；请求具备加载、成功、错误、空状态。统一使用 Lucide 图标，提供键盘焦点、语义标签和减少动态效果支持。
