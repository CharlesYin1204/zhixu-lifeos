# 页面加载故障修复记录

状态：修复已部署至独立release .releases/20261014T124600Z-11885，公开IP:3060转发3061健康检查通过；Chromium 145与156各52步完整导航回归通过，修复验收完成。

## 触发与根因

用户反馈 AI 助手及其他页面出现“This page couldn’t load”。在 Chromium 156 中访问 AI 页面后切换或恢复会话，复现 React 运行时错误 `TypeError: i is not a function`，随后进入全局错误页。复现报告保留 URL、错误堆栈和操作步骤。

同一滚动调用在实际测得的 Chromium 145 中返回 `undefined`，在 Chromium 156.0.8078.4 中返回 `Promise`。AIChat 的 `useEffect` 原先使用表达式函数体，隐式把 `scrollIntoView()` 的返回值交给 React。React 在效果清理时尝试调用该值，新浏览器返回的 Promise 不是可调用函数，因此抛错。这解释了早期 Chromium 145 验收通过而新浏览器仍出现故障的差异；不能据此推定所有浏览器版本都具有同样返回行为。

## 已落盘修复

`components/LifeOS.jsx` 将该 effect 改为块体，只执行滚动，不返回 DOM 方法的值。当前源码的12个 effect 回调已做静态检查，全部为非 async 块体；这一检查本身不替代页面回归。

部署使用独立release构建和候选健康检查后切换，已实际切换至.releases/20261014T124600Z-11885。旧.next保留，worker本轮未重启，公开3060→3061健康。发布日志位于private/browser-hotfix-publish.log。自动回滚路径未专项实测。
